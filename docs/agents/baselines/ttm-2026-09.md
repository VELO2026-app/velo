## Метод

- Источник: Linear API, 2026-09-17; команды Frontend и Backend, по 14 последних закрытых тикетов (по `updatedAt`).
- **TTM = `createdAt` → `completedAt`** (UTC, в днях). Включает время в бэклоге — отделить «очередь» от «работы» этими полями нельзя; это честная граница метода.
- Даты git-мержей не используются: история идёт прямыми коммитами в `test`, дата закрытия issue точнее отражает приёмку.
- GT-тикет (кураторские группы) в выборку не попал: среди команд воркспейса (Frontend, Backend, PM, Design) ключа GT нет; при необходимости добавить отдельным замером.
