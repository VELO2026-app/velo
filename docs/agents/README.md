# docs/agents/ — реестр managed agents фабрики

Часть плана миграции на «фабрику разработки» (`docs/ai-dev-factory-tz.md`, п. 8.4, Фаза 0).

## Железное правило

**Ни один агент не входит в боевой процесс без карточки, evals и известной стоимости** (п. 5.2 ТЗ). Нет карточки — нет запуска, независимо от того, насколько агент «уже работает».

## Как это устроено

- **Карточки, evals и результаты запусков живут здесь, в репозитории** — один текст, как и для остального кода (п. 8.5.3 ТЗ). Никаких карточек в чатах и вики.
- **Шаблон заполняет агент, человек утверждает** (риск «церемония», п. 10.1 ТЗ): человек не секретарь фабрики.
- **Стоимость до Фазы 5 фиксируется хотя бы вручную** в поле «Стоимость» карточки (п. 8.5.4 ТЗ). Ничего не оптимизируем «по ощущениям».
- **Evals — блокирующий гейт** любого изменения модели, промпта или источника контекста (п. 5.6 ТЗ).
- **Права агента перечислены в карточке**; нет права в карточке — нет права в токене (п. 5.7 ТЗ). Полное закрытие доступов и секретов — до Фазы 2.

## Состав

| Файл | Что это |

| `template.md` | Шаблон карточки managed agent (п. 5.2 ТЗ) |

| `baselines/` | Замеры «до»: TTM и другие точки сравнения для гейтов фаз |
| `phases.md` | Трекер фаз 0–6 с гейтами (Linear F-тикеты отложены, решение владельца 2026-09-17) |

## Как добавить агента

1. Скопировать `template.md` в `<имя-агента>.md`.
2. Заполнить все секции; незаполненное помечать явно (`не заведено` / `до Фазы N`), пустых полей не оставлять.
3. Владелец утверждает карточку.
4. Только после утверждения — боевой процесс.
