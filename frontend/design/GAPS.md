# GAPS.md — что Figma-зеркало не выражает

> Код — источник правды, страница `front` в Figma («VELΘ App Актуальное») —
> зеркало. При расхождении правится зеркало, не код. Этот файл фиксирует всё,
> что зеркало **принципиально** не может показать, чтобы дизайн/агент не
> «додумывали» поведение по статичной картинке.

## Непереносимое (живёт только в коде/Storybook)

| Что | Где в коде | Почему не переносится |
|---|---|---|
| **Faux-bold 600** | `VButton.vue` (label), `VHeader.vue` (title) | У Marmelad одно начертание; браузер синтезирует weight 600, Figma — нет. Кнопки/заголовки в зеркале выглядят легче, чем в приложении. Это ожидаемо, не расхождение. |
| Focus order, `:focus-visible`, ARIA | все компоненты; `useKeyboardFieldScroll` | Поведение, не статика. |
| Поведение клавиатуры TMA | `platform/dom`, `.velo-kbd-scroll`, `--velo-vvh` | Скролл-контейнеры/заморозка высоты — рантайм. |
| `env(safe-area-inset-bottom)` | `VTabBar.vue`, `VAdminTabBar.vue` | Figma не знает платформенные инсеты. |
| Backdrop-filter | `VBackButton · glass` (blur 18/180%), `VTabBar` (blur 12/150% + блик soft-light) | В Figma — условный background-blur/градиент; настоящая формула стекла — в CSS. |
| Анимации и тайминги | `motion.css`, `--velo-dur-*`, `--velo-ease-*`, skeleton delay 300ms / hold 450ms, пульс скелета 1.8s, спин VeloLogo 120s/об., `VLoadingSwap` crossfade | Переходы не живут в статике. |
| Letter-spacing в `em` | `VListRow` (.02em), `VConfirmDialog` title (.02em) | Figma-стили хранят px; em-значения привязаны к размеру шрифта. |
| Telegram-платформа | haptics, viewport, `@tma.js/sdk` | Вне Figma. |
| Редакции/фича-флаги | `PRIMER_EDITION` → `editions.json` → `__VELO_FEATURE_*__` | Дерево сборки, не дизайн. |

## Условности зеркала

- Заливки зеркал привязаны к переменным `velo.*`; скины (`skins/*.tokens.css`)
  перекрашивают зеркало сменой значений коллекции, а не правкой узлов.
- Состояния, которых нет в `variables.css` (focus/error-рамки форм), собираются
  из тех же токенов; источник значений — CSS компонента.
- Сцены (VModal, VConfirmDialog, PracticeAnalytics) — иллюстрации сборки,
  контент-примеры не каноничны; каноничны только COMPONENT-мастера.

## Как поддерживать

1. Каждая миграция батча (P2–P6 из `tz-ui-package.md`) несёт: код + сторю +
   зеркало в `front` + Code Connect — и, при необходимости, строчку здесь.
2. Приёмка зеркала — агентом через Figma MCP: свойства узла сверяются с CSS
   компонента (см. аудит 2026-11-07: VSelect focus, обводки чекбокса/радио/дней,
   пилюля VMoreLink и т.д. — правились по коду).
3. Новый компонент = код + зеркало + строка в `component-map.md`; если его
   вид нельзя выразить статикой — строка здесь.
