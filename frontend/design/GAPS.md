# GAPS.md — что Figma-зеркало не выражает

> Код — источник правды, страница `front` в Figma («VELΘ App Актуальное») —
> зеркало. При расхождении правится зеркало, не код. Этот файл фиксирует всё,
> что зеркало **принципиально** не может показать, чтобы дизайн/агент не
> «додумывали» поведение по статичной картинке.

## Непереносимое (живёт только в коде/Storybook)

| Что | Где в коде | Почему не переносится |
|---|---|---|
| **Faux-bold 600** | `VButton.vue` (label), `VHeader.vue` (title) | У Marmelad одно начертание; браузер синтезирует weight 600, Figma — нет. Кнопки/заголовки в зеркале выглядят легче, чем в приложении. Это ожидаемо, не расхождение. |
| Focus order, `:focus-visible`, ARIA | все компоненты; `useKeyboardFieldScroll` | Поведение, не статика. |
| Поведение клавиатуры TMA | `platform/dom`, `.velo-kbd-scroll`, `--velo-vvh` | Скролл-контейнеры/заморозка высоты — рантайм. |
| `env(safe-area-inset-bottom)` | `VTabBar.vue`, `VAdminTabBar.vue` | Figma не знает платформенные инсеты. |
| Backdrop-filter | `VBackButton · glass` (blur 18/180%), `VTabBar` (blur 12/150% + блик soft-light) | В Figma — условный background-blur/градиент; настоящая формула стекла — в CSS. |
| Анимации и тайминги | `motion.css`, `--velo-dur-*`, `--velo-ease-*`, skeleton delay 300ms / hold 450ms, пульс скелета 1.8s, спин VeloLogo 120s/об., `VLoadingSwap` crossfade | Переходы не живут в статике. |
| Letter-spacing в `em` | `VListRow` (.02em), `VConfirmDialog` title (.02em) | Figma-стили хранят px; em-значения привязаны к размеру шрифта. |
| Telegram-платформа | haptics, viewport, `@tma.js/sdk` | Вне Figma. |
| Редакции/фича-флаги | `PRIMER_EDITION` → `editions.json` → `__VELO_FEATURE_*__` | Дерево сборки, не дизайн. |

## Условности зеркала

- Заливки зеркал привязаны к переменным `velo.*`; скины (DTCG-пакеты в своих репозиториях, `tokens/*.tokens.json`, FE-131)
  перекрашивают зеркало сменой значений коллекции, а не правкой узлов.
- Состояния, которых нет в `variables.css` (focus/error-рамки форм), собираются
  из тех же токенов; источник значений — CSS компонента.
- Сцены (VModal, VConfirmDialog, PracticeAnalytics) — иллюстрации сборки,
  контент-примеры не каноничны; каноничны только COMPONENT-мастера.

## Мастера только в Figma (без аналога в коде)

## Миграция на FSS v1 (FE-154), состояние на 2026-11-09

Стандарт: скилл `code-to-figma-pixel-perfect`, `references/figma-standard.md`.
Всё на одной странице `front` (D-2 «разбить на страницы» отменён владельцем).

- **Страница.** Старая `front` удалена после переноса; рабочая копия переименована в
  `front`. Колонки слева направо: `Cover`, `Registry / …`, `Asset / App background`, `Templates`; листы `Component / …`;
  листы экранов; архив старых секций (подписи, `In context`, Goodo, старый реестр токенов
  с доской «Audit & skin diff (2026-11-06)»). Откат: история версий файла.
- **Мастера.** 221 мастер (плюс 2 шаблона), каждый в одном экземпляре; id прежние, все
  44 ссылки `component-map.md` (мастера и листы композитов) проверены 2026-11-09. При копировании страницы появились 62 копии наборов
  вариантов: экземпляры переключены на оригиналы, копии удалены. Журнал переноса лежит
  в `pluginData` файла (`c2f-migration-log`). Битых экземпляров нет.
- **Описания мастеров.** У всех: `Code:` путь, `Props:` из кода (у 27 мастеров пропсов
  нет или их не удалось прочитать), `Map:` раздел и строка карты, где она есть.
- **Фундамент.** Коллекция `doc` (цвета и шаги сетки листа), стили
  `doc/title|section|caption|body` (Inter), шаблоны `Template / Sheet Header` и
  `Template / Status Badge`. Библиотека `figma-lib.js` v2 в скилле.
- **Чистые по аудиту (0), статус `built`:** `Cover`, `Templates`, `Registry / legacy`,
  `Registry / velo`, `Asset / App background` (кадр фона `3997:11230`).
- **Экраны: ни один не соответствует стандарту.** Все четыре листа называются
  `Legacy screen / …`: в рамках нет каркаса `Background` / `Content` / `TabBar` / `Overlay`
  (S-20), элементы лежат свободно. Собрать каркас значит переразложить экран, а это
  проверяется только `diff.py`. Аудит раньше показывал у Dashboard и Practices 0 из-за
  слишком широкого исключения S-60; исправлено, аудит теперь проверяет каркас.
- **Листы компонентов** (`draft`): строки по образцу `Practices, bookings & chats`, шапки —
  экземпляры `Template / Sheet Header`. Открытые замечания внутри мастеров (всего по странице
  1019, исключений `c2f:raw` 170): автовысота строки у текстов со стилем `velo/fs-*`, текст
  без стиля, дробные позиции, рамки без Auto Layout, белый `#ffffff` с четырьмя кандидатами
  в переменные. Счётчики по листу — в `c2f:audit` секции.
- **Стили оформления листа:** только `doc/title|section|caption|body`; 12 старых
  `doc/SemiBold-22`, `doc/Regular-10` и т. п. удалены (тексты архива остались без стиля).
- **Маршрут экрана «Практики»** (`user.calendar`) определён по названию вкладки; проверить.
- **`diff.py` не запускался:** нужен рендер с входом, демо-входа нет. Во всех рамках
  состояний `diff = LIMIT not measured`.
- **Типографика (2026-11-10).** В коде токенизирован только размер (`--velo-fs-*`); высота
  строки и интервал задаются в компонентах (17 и 20 разных значений). Поэтому в Figma стили
  собраны по реальным сочетаниям: `velo/fs-<размер>/lh <px>[ · ls 0.02em]`, 23 стиля,
  применены к 184 текстам мастеров без изменения размеров. 69 текстов с дробным
  размером (масштабированные превью: `DiaryThreadCard`, `DiaryTimeline`, `DiaryFeedCard`,
  `MoodSlider`) помечены исключением `c2f:raw`. Осталось 385 текстов с автовысотой
  строки (старые стили `velo/fs-*` и часть текстов без стиля): их высоту надо измерить в
  рендере приложения. Storybook для этого не годится: он не подключает глобальные стили
  приложения (`body { line-height: 1.5 }`), и текст там рендерится с `normal`.
- **Рендер с входом возможен:** локальный стенд `~/work/velo-dev` с дев-логином
  (`dev-initdata.py`) даёт авторизованную сессию. Утверждение «демо-входа нет» устарело;
  через стенд можно измерить текст и прогнать `diff.py` для экранов.
- **Остаток сверки — по запросу, без отдельной задачи** (решение владельца 2026-11-10):
  источник правды — код, Figma — зеркало, регрессии ловят FE-161 и FE-162. Замер высоты
  строки в мастерах, `diff.py`, каркас Legacy-экранов и перенос остальных экранов делаются
  точечно, когда конкретный экран или компонент нужен в Figma, на стенде FE-161 (сид,
  логин по ролям, параметры роутов).
- **Линт:** в `frontend/.stylelintrc.json` для `line-height` и `letter-spacing` разрешены
  только уже используемые значения или `var(--…)`. Попутно починено: из-за
  `customSyntax: postcss-html` проверка токенов не работала для обычных `.css`-файлов;
  для `*.css` теперь стоит `postcss` (нарушений в существующих `.css` нет).

## Как поддерживать

1. Каждая миграция батча (P2–P6 из `tz-ui-package.md`) несёт: код + сторю +
   зеркало в `front` + Code Connect — и, при необходимости, строчку здесь.
2. Приёмка зеркала — агентом через Figma MCP: свойства узла сверяются с CSS
   компонента (см. аудит 2026-11-07: VSelect focus, обводки чекбокса/радио/дней,
   пилюля VMoreLink и т.д. — правились по коду).
3. Новый компонент = код + зеркало + строка в `component-map.md`; если его
   вид нельзя выразить статикой — строка здесь.
