# EN glossary / терминологический глоссарий (tz-i18n phase: en)

Единственный источник терминологии для `src/locales/en/**`. Правила:
англицизмы продукта сохраняются; предложения — sentence case; кнопки и
лейблы — без точки; полные предложения — с точкой; plural — 2-формные
пайпы `one | other`; literal `@` — только `{'@'}`.
